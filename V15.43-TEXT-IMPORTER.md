## Regras do formato

- Use `Ataque: NOME` para iniciar cada ataque.
- Use `Habilidade: NOME` para iniciar cada habilidade.
- Cada campo abaixo do ataque/habilidade pertence a ele ate o proximo Ataque/Habilidade ou secao.
- `Condicoes:` aceita varias condicoes separadas por virgula. `Duracao:` vale para todas as condicoes daquela acao.
- `Area: Sim` marca a acao como area. `Tipo: Area` tambem e reconhecido pelo motor.
- Para habilidades com resistencia, escreva no Efeito de forma explicita, por exemplo: `o alvo faz teste de Vigor` ou `se falhar no teste`.
- `RES: 1..4` ativa o fluxo de Ressonancia para habilidades elementais do inimigo. Use 0 quando nao houver Ressonancia.
- Campos vazios podem ser deixados em branco.

## Limitacoes que continuam intencionais

- O importador nao inventa valores ausentes; a tela de revisao usa defaults somente ao salvar campos ainda vazios.
- Uma acao possui uma unica duracao estruturada para todas as condicoes listadas nela.
- Imagem continua sendo adicionada pelo editor visual do Bestiario.
- Regras narrativas complexas permanecem no campo Efeito/Descricao e podem exigir decisao manual do Mestre.
