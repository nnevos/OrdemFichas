ARQUIVO DA ORDEM - SUPABASE CONFIGURADO (frontend)

1. O arquivo ordem-config.js ja contem a URL e a chave PUBLICA fornecidas.
2. No Supabase > SQL Editor, execute CONFIGURAR-SUPABASE-ORDEM.sql.
   O SQL anterior criou campaigns/characters, mas a aplicacao utiliza
   ordem_campaigns/ordem_characters; o novo SQL cria as tabelas corretas.
3. Publique a pasta skill-tree-rpg em hospedagem estatica HTTPS,
   ou teste localmente com: python3 -m http.server 8000
4. Abra index.html no servidor; crie uma campanha e uma ficha.
5. Abra o site em outro navegador/dispositivo e confira a sincronizacao.

AVISO: esta versao usa acesso PUBLICO SEM LOGIN, conforme solicitado.
Qualquer pessoa que obtenha a chave publica pode ler, editar ou apagar
qualquer campanha/ficha; o painel do mestre nao e uma area protegida.
Nao use dados privados. Antes de disponibilizar amplamente, implemente
controle de acesso por campanha com backend/Edge Function.
A conexao com o Supabase real nao foi testada neste ambiente.
